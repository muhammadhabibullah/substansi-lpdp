# Contoh dokumen / Example documents

Dokumen **fiktif** untuk mencoba aplikasi tanpa memakai berkas asli Anda.

Semua nama, institusi, angka, dan capaian di sini adalah karangan. Jangan pakai
sebagai templat lamaran sungguhan — tujuannya hanya agar Anda bisa merasakan
alur wawancara dan bentuk laporannya.

## Cara pakai

1. Buka halaman **Pengaturan** dan atur endpoint LLM Anda.
2. Buka halaman **Persiapan**.
3. Isi profil dengan data contoh di bawah.
4. Untuk setiap slot dokumen, pilih tab **Tempel teks** lalu tempel isi berkas
   yang sesuai.

## Berkas

| Berkas | Slot di aplikasi |
|---|---|
| [`cv-magister.txt`](./cv-magister.txt) | CV / riwayat hidup |

## Profil contoh (Magister, luar negeri)

| Field | Nilai |
|---|---|
| Nama lengkap | Sri Wahyuni |
| Jenjang | Magister (S2) |
| Tujuan studi | Luar negeri |
| Universitas tujuan | University of Melbourne |
| Program studi tujuan | Master of Public Health |
| Status LoA | LoA Conditional |
| Skema beasiswa | Reguler |
| Bidang keilmuan | Kesehatan masyarakat / epidemiologi lapangan |
| Pekerjaan saat ini | Staf surveilans di Dinas Kesehatan Kabupaten Bantul |
| Bahasa wawancara | Bahasa Indonesia + segmen bahasa Inggris |

## Profil contoh (Doktor, dalam negeri)

Pakai `proposal-doktor.txt` bersama `cv-magister.txt` dan `esai-kontribusi.txt`.

| Field | Nilai |
|---|---|
| Nama lengkap | Sri Wahyuni |
| Jenjang | Doktor (S3) |
| Tujuan studi | Dalam negeri |
| Universitas tujuan | Universitas Gadjah Mada |
| Program studi tujuan | Doktor Ilmu Kedokteran dan Kesehatan |
| Status LoA | Belum punya LoA |
| Skema beasiswa | Reguler |
| Bidang keilmuan | Epidemiologi penyakit menular |
| Pekerjaan saat ini | Staf surveilans di Dinas Kesehatan Kabupaten Bantul |
| Bahasa wawancara | Bahasa Indonesia |

> Catatan: contoh ini sengaja dibuat "cukup baik tapi belum sempurna" — ada
> bagian yang normatif dan angka yang kurang spesifik, supaya panel punya bahan
> untuk menggali dan laporannya menunjukkan saran perbaikan yang nyata.
